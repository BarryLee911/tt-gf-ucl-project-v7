# v7：23 位分频、峰值选择重排与 AREA 0 对比

**结果：相对 v6，最差 setup 恶化 0.304810 ns；面积变化 +1.008%；功能 PASS；九角时序 FAIL。**

## 修改与实验条件

- 分频计数器、锁存终值、终值连线由 27 位缩为 23 位，所有合法档位保持 2^level 周期。
- 峰值候选的最终独热来源直接由比较与存活条件生成；第二有效位简化为任一候选存活。数值、位置、相等幅值优先级和无效槽行为保留。
- 继续使用 v7 仓库，恢复 AREA 0；顶层与引脚、配置锁存、复位、N/N+1/N+2 节拍、80 MHz、2.5 ns IO、4×2、密度及 hold 修复参数一致。
- 实验提交 `6a0745e8885cb8a88764bf30a45a7e36faaf0df1`；分频提交 `e4a65de020d02f448a1fe53a15ca3d6d51c421a6`；峰值提交 `54b570d853efb6214eff0b4d0ba0031c9a79ce24`。
- v6 RTL SHA256：`E070E8658952FF7314BFD6CE7E69E035233953CCCED5E57FA44714AE7D9F2FE2`；新版：`54345977664514456EF74C2CDCDB114BE37523DA76E48CA9FCDB1144F9EE9088`。新版提交、实现源文件和 RTL 仿真快照一致。
- 固定 LibreLane 3.0.14、GDS action 395eedb、支持工具 01d5d28、实现与门级 PDK 54435919。precheck 沿用该 action 自带 e8daeda 检查 PDK。
- 最终解析的 30 项配置、工具版本、源文件和约束审计通过；源码实现配置与 v6 AREA 0 完全一致。全部归档 SHA256 与 GitHub digest 一致。

## 功能、物理与验收

- 标准 RTL：PASS，460637 个真实时钟周期。
- 分频与峰值并行比较：PASS，468829 周期，所有输出及峰值数值、位置、有效位每拍一致，四种存活状态均覆盖。
- SAT：PASS，取自原版与新版真实 RTL 的 37 位峰值下一状态，对所有二进制组合输入等价；不声称四态或物理延迟的形式证明。
- level 23：PASS，25166114 周期，三个真实采样在 8388608、16777216、25165824 拍；无强制状态，输出每拍检查。
- GDS 构建：PASS；DRC/LVS/路由/天线：PASS，计数 `{'magic__drc_error__count': 0.0, 'design__lvs_error__count': 0.0, 'route__drc_errors': 0.0, 'antenna__violating__nets': 0.0, 'antenna__violating__pins': 0.0}`。
- precheck：success；门级功能：PASS，460637 周期，未使用 SDF。
- 门级检查保留从第一复位边沿开始的 X/Z 检查；上一轮第 32 拍的失败点没有屏蔽。
- 九角 setup/hold：FAIL；slew/capacitance/fanout：FAIL。物理流程沿用 v6 的 TT setup gate，独立九角检查的失败仍正式报告。
- TT/FF 六个角的 setup 通过，三个 SS 角的 setup 失败；九个角的 hold 全部通过。
- RTL 功能接受：PASS；完整时序、电气与功能验收：FAIL。

本轮评估两项 RTL 合并后的物理收益，不把总改善分别归因于分频或峰值修改。若仍有负 setup，保持 80 MHz 目标记录其真实余量，不能据构建完成宣称全角时序收敛。

## 下一步判断

本轮没有改善相对 v6 的最差 setup，面积也增加，暂不认定为更优的物理实现。功能结果与时序结果分别保留。
最差路径从峰值候选选择转移到 prescale_count → 终值比较/采样使能 → history_pointer 的组合链。下一轮优先评估提前计算采样使能、把终值比较与位置计数进位拆到不同寄存器路径，同时保持首次采样、level 0 吞吐和 N/N+1/N+2 节拍；此项尚未实施。
